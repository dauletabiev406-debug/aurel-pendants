# AUREL — Ближе к сердцу

Кинематографичный сайт коллекции кулонов. HTML, CSS и JavaScript без зависимостей.

## Структура

- `index.html` — структура и основные тексты.
- `style.css` — оформление и адаптивная версия.
- `app.js` — 236 кадров скролл-сцены, подбор кулонов, избранное и эффекты фотографий.
- `assets.tar.gz` — фотографии, кадры, исходное видео и локальные шрифты. Архив сохраняет структуру `assets/` и распаковывается автоматически при публикации.
- `.github/workflows/pages.yml` — публикация в GitHub Pages при обновлении `main`.

## Локальный просмотр

Распакуйте `assets.tar.gz` рядом с `index.html`, затем запустите любой статический HTTP-сервер. Открытие через `file://` не поддерживает загрузку кадров через fetch.

## Публикация

Источник в Settings → Pages: GitHub Actions. Workflow публикует HTML, CSS, JS и распакованные ресурсы, без архива и служебных файлов.

Названия и описания украшений — авторская концепция. Оплата и отправка заявок не подключены.
